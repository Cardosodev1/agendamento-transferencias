# Frontend — Agendamento de Transferências

SPA em Angular 22. Instruções de execução, decisões e arquitetura estão no [README principal](../README.md).

```bash
npm install
npm start        # http://localhost:4200 (proxy de /api para http://localhost:8080)
npm test         # testes unitários (Vitest)
npm run build    # build de produção em dist/
```
